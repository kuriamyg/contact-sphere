# Contact Sphere

A privacy-first contact management platform built with Next.js and NestJS, featuring intelligent duplicate detection, safe contact merging, relationship mapping, VCF import/export, encrypted backups, and a scalable foundation for future personal and organizational use.

## Features

- **Privacy-First Design** - Your data stays under your control with end-to-end encryption
- **Intelligent Duplicate Detection** - Automatically identify and safely merge duplicate contacts
- **Relationship Mapping** - Visualize and manage contact relationships and networks
- **VCF Import/Export** - Full support for vCard format import and export
- **Encrypted Backups** - Secure backup and restore functionality
- **Scalable Architecture** - Built for both personal and organizational use
